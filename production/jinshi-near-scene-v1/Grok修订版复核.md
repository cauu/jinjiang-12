# Grok 4.7 修订版独立复核

我先对照设计参考、三张预览图和近景源码，只核对手机左右的丰富度、重复、预留空间、遮挡和贴片感，并分开写截图能看见的与还没验证的部分。修订版近景在这三张图上不能算通过。左右有摊位和货架，但相对概念图仍然空、重复，并且货架与近景货物是朝北的平面贴片。自动测试没有纳入这次判断。

## 未通过

1. **左右不够丰富。** 概念图两侧是不同的摊、布匹、织机、推车和人群，前景还会压住棋盘。`锦市-手机.png` 的镜头基本朝北，左右市集只剩画面边缘一条，看不出丰富度。`edge--9-0.png` 左侧是一排布棚摊加整面货架，摊与栏杆之间是空沙地，没有成组货物和路人。`edge-9-0.png` 右侧同样是布棚摊和货架，多出一辆纺织品推车和几个箱子，仍然没有概念图那种两侧各自成市的密度。

2. **左右在重复。** 源码里两侧各五座摊，位置是 `x=±12`、`z=-8,-5,0,5,8`，结构相同，只有棚布颜色轮换。每座摊前再挂同一块布，按 `z` 在红、靛之间交替。近景只有三张贴图，西侧顺序是丝绸、筐瓮、推车、丝绸，东侧是筐瓮、推车、丝绸、筐瓮，并且东侧整张 `scale.x=-1`。中央与东侧市集立面用同一张 `mobile-market-cutout`，东侧同样镜像。两张边图里的货架墙模块也看得出是同一套图案。

3. **后续模型的空档留了，但看起来是空地。** 摊位在 `|x|=12` 以外，近景贴片在 `|x|=16.5`，注释写明摊位靠场地一侧和棋盘要留给以后的模型。两张边图里，栏杆和摊位之间确实有一条没被挡住的沙地。中心手机图看不到这条空档。它没有被摊位填死，可也没有做成能看出“这里还要放模型”的市集前景。

4. **遮挡只有一层。** 边图里棚顶和柱子挡住了后面一部分货架，这是仅有的清楚前后关系。中心手机图前景是空地和栏杆，没有人、布或推车压住棋盘边缘。概念图靠这种遮挡建立深度。源码在 `x≈±12.2` 和 `±14` 放了纸片人，这两张边图里几乎看不到他们挡在摊位前面。

5. **二维贴片感还在。** 货架墙和近景货物都是 `PlaneGeometry` + `MeshBasicMaterial`，不吃光照，用 `alphaTest` 抠边。平面法线朝 ±Z，也就是朝北，不是朝向场地。人站在西侧或东侧朝北看，会正对贴片；朝正西或正东看，这些面会变成一条边。东侧那辆推车在 `edge-9-0.png` 里更像画在板上，而不是有体积的车。摊位棚顶、立柱和坐垫是有厚度的盒子，这块不是贴片。
