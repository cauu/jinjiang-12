# 锦市手机近景样板

基于 `docs/concepts/01-jinshi-paper-concept-v3.png` 的色彩、布匹、染缸、竹筐和货物组合制作。`原图/` 为 4 张内置 imagegen 生成的透明 PNG；`提示词/` 保存实际调用内容。游戏使用压缩后的 WebP，独立放在 `packages/game-client/src/assets/jinshi/`，未覆盖原有素材。

- `silk-goods`：锦布货架与布卷。
- `baskets-vats`：染缸、竹筐与织物。
- `market-cart`：运货车。
- `varied-shops`：不同类型的商铺，用于替换一处重复街市画面。

场地左右各放 4 组货物图，中心约在 x = ±16.5，位于 z = -11、-5、1、7；北侧另有两组，中心约在 x = ±8.4、z = -15.4；它们为无碰撞的竖直平面，在现有棚位外侧。赛场 |x| ≤ 10 内不放新增装饰，场地和现有棚位之间未新增贴片，但现有棚位本身以及更外侧的贴片仍占空间；后续模型需要根据实际尺寸调整或替换装饰，不能保证任意模型都能直接放入。远景仍有重复商铺，近景为二维贴片，会随镜头位置暴露平面感；本次不是最终模型或完整场景。

`修订预览/` 包含浏览器运行截图和九个采样位置截图，定位通过服务端设定，不能代替真实手机实走。构建、三种横屏比例镜头、九点角色遮挡、行走涂色，以及图片资源加载检查通过。未进行实体手机性能测试、最终美术验收或所有角色互相遮挡的验证。
