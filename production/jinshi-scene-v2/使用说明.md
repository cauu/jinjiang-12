# 锦市场景素材 · 第二批（2026-10-30）

`原图/` 是 gpt-6.1-terra（high）生成的原图，`提示词/` 是每张图实际使用的提示词，参考图均为 `docs/concepts/01-jinshi-paper-concept-v3.png`。`预览/` 是平铺、接缝和染色效果的检查图。
