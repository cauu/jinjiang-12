# 《锦江十二月市》素材与场景设计交接

本目录以当前 `game-backend-mvp` worktree 的实现为基线，制作日期 2026-10-28。它是生产规划与可评审设计稿，非美术成品或游戏实机验收。

- `素材生产清单.csv`：UTF-8 BOM，Excel 可直接打开。沿用草稿编号，新增 14 个编号，含 7 套天空盒与大厅远景复用方案；每行列出制作状态、建议岗位、待认领负责人、优先级、规格、依赖、实际参考路径与可执行 AI 提示词或人工处理说明。提示词为本次新写的生产指令，不是历史生成调用记录。路径均相对于仓库；合并到 main 后，尚未提交的实现及运行资源引用使用 `基线快照/` 下的只读副本，角色原始 Blender 使用备注中的主工作区绝对路径。CSV 中实际参考路径指向现存文件，交付格式与位置可为未来交付目标，并不代表目标已经存在。
- `界面设计稿.html`：离线打开；7 套俯视锚点图与手机、大屏的三阶段组件布局，桂市另补结局视频状态。方块是可拆分 UI 线框、动态字段和场景占位示意，准确的尺寸、绑定、权限、验收条件见规格。
- `场景与交互规格.md`：服务器状态、时间线、七个场景的坐标、交互、文案、素材 ID、验收条件，以及现有行为和需要开发接入的区别。
- `视觉参考/`：从原草稿原样复制的七张 AI 六格图，仅供色彩和氛围参考；图内按钮、时长、人数、结果及排版不作依据。没有将草稿中简化版 Prompt 声称为实际生成记录。六关原始概念图、原 Prompt 和概念评审留在 `docs/concepts/manifest.json` 所指的文件中，概念通过不代表生产验收通过。
- `基线快照/`：当时 game-backend-mvp 中的服务端、双端、共享客户端和共享协议源码、角色资源、测试视频及占位说明的只读副本。仅供设计溯源，不是已合并到 main 的游戏实现；实际运行仍需对应开发工作独立集成。
- `复核记录.md`：交付文件核对与独立复核结果，列出未完成项。

团队按编号认领，在 CSV 中填写实际负责人和日期；素材从参考发展成正式资源后更新状态与可交付路径。现有程序天空为纯色，天空盒和远景均待制作、接入和双端验收。场景锚点是摆放提案，实际模型、贴图、音频、影片、内容审校和开发集成仍待完成。视频现有八条均是测试占位；四个开场的含义尚待确认，代码仅一个 intro，不擅自增加播放节点。
