# 锦江十二月市 · 多人游戏白模

Node.js 22 + npm workspaces。手机端、大屏端共用网络和 Three.js 白模，服务器控制六关、计时和结算。当前是研发中白模，验收状态见 [验收标准与清单](docs/development/acceptance.md)。

```sh
nvm use
npm ci
npm run dev
```

本机大屏 `http://localhost:5174/`；大屏展示手机加入二维码，手机端为 5173。真机扫码时应使用开发机在同一局域网内可访问的 IP 打开大屏，以便二维码包含该 IP。现有开发服务器仅供现场演示使用；管理端通过 `/admin/bootstrap` 自动获取控制权限，没有登录或访问隔离，应仅在可信演示网络中运行。

微信扫码后会先显示浏览器打开指引，复制或通过微信菜单打开完整链接，再输入昵称入房。iPhone Safari 可在页面菜单选择「更多 → 隐藏工具栏」以增加画面；安卓浏览器支持时会尝试全屏。实际微信菜单、真机兼容和手感仍需现场验证。

如果默认的后端 3000 端口被占用，可以通过 `PORT=3300 npm run dev` 同时切换后端端口及两个前端的代理目标。

大屏大厅可点击「添加 9 个机器人」补充玩家，重复点击可继续添加，最多 32 位参赛者；无人加入时会给真人保留一个位置。机器人按简单策略操作并遵守服务端规则，开局前可用「移除机器人」清空；对局中先点击「重新开始」才能调整。它们用于试玩，不代表真人水平，也不能替代真人验收。

```text
apps/mobile       手机页面
apps/display      大屏和控制页面
apps/server       游戏服务及规则
packages/shared   前后端协议和公共类型
packages/game-client  共享连接及白模渲染
assets/video      四段测试过场及手机副本
```

质量检查：`npm run build` 检查类型并构建两端；`npm test` 运行后端测试；`npm run test:acceptance` 顺序运行所有后端及浏览器测试，包括 30 人完整对局，需 Chrome、较多资源和数分钟。可用 `CHROME_PATH` 指定 Chrome。各单项测试命令见 `package.json`，具体覆盖范围和未完成项目见验收清单。详见 [服务端与接口说明](apps/server/README.md)。正式题库、美术、视频和真机/现场验收尚未完成。
