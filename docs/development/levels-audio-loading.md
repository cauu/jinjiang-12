# 关卡视图、素材加载与音效

日期：2026-10-30。

## 关卡视图（`packages/game-client/src/levels/`）

每关的 3D 表现集中在一个工厂函数里，`SceneView` 只负责玩家、相机和渲染。每关提供：

| 项 | 说明 |
|---|---|
| `LEVEL_ASSETS[关卡]` | 本关要用的图片与模型 URL，供预加载 |
| `createLevel(id)` → `group` | 场景、地砖、道具、物品；切关时整体加入或移出 |
| `update(frame)` | 每帧更新本关的地砖颜色、物品和反馈特效 |
| `dispose()` | 离关时释放显存 |
| `background` / `camera` | 背景色；手机相机的前视距离与抬高 |

新增一关的场景或美术时，只改该关的工厂函数，并把素材 URL 加进 `LEVEL_ASSETS`。允许硬编码坐标。

### 已实现的玩法反馈

| 关卡 | 反馈 |
|---|---|

## 素材加载（`preload.ts`）

- 开启 `THREE.Cache`。`TextureLoader` 和 `GLTFLoader` 按 URL 命中缓存，所以预加载只需把文件读进缓存，各关的加载代码不用改。
- 手机打开页面就开始预加载：先加载角色，再按关卡顺序加载各关素材，同时下载 3 个文件。入场页和大厅显示"资源加载 xx%"。进度按 10% 一档上报给服务端，大屏显示"已就绪 N/M"，未加载完的玩家后面显示百分比。
- 开局后仍未下载完的素材，在卡片和过场视频期间继续下载。纹理到达后自动显示，不会阻塞对局。
- 角色模型 `hanfu-boy.glb` 已压缩：几何体用 meshopt 压缩并量化，贴图改为 WebP，体积从 4.5MB 降到 0.75MB，加载端启用 `MeshoptDecoder`。人群图集与蒙版改用无损 WebP，可见像素与原 PNG 一致。命令见 `tools/character/README.md`。
- 手机端构建产物合计约 9.4MB，其中 Rapier 物理引擎单独打包为 4.3MB（gzip 后约 1.6MB）并按需加载，其余约 5.3MB。

## 音效（`audio.ts`，Howler.js）

- 所有短音效打包成一个 64kbps 单声道 MP3 音频精灵（`assets/audio/sfx.mp3`，约 208KB，44 段），一次请求、一次解码。大屏背景音乐 `market-loop.mp3` 约 129KB，以流式方式播放。
- 来源：Kenney 的 CC0 音效包（界面、撞击、RPG、娱乐场、数字音、短乐句），可免费商用，无需署名。选用的原始文件和授权文件在 `tools/audio/source/`，清单在 `tools/audio/sounds.json`。重新生成：`node tools/audio/build-audio.mjs`（使用 `ffmpeg-static` 提供的 ffmpeg）。

| 触发来源 | 声音 | 播放端 |
|---|---|---|
| 本地预测（零延迟） | 跳、落地（按下落速度分轻重）、脚步（按关卡区分布面、木、石、土的材质，每 0.3 秒一步） | 手机 |
| 服务端确认 | 捡交子（铜钱声）、扛粮袋（布料声）、交付（陶罐声）、染色（拨弦声）、脚下石板开裂、掉落、提前晋级、保底救回 | 手机 |
| 阶段 | 卡片翻书、倒数木鱼、开始钟声、晋级、淘汰、夺冠乐句和锣声 | 手机（音量较小）和大屏 |
| 关卡环境 | 背景音乐（市散除外，留给风声）、灯市最后 3 秒滴答和揭晓锣声、市散崩落、桂市台阶塌落 | 大屏 |

- 重复出现的声音每次随机选一个变体，音高随机浮动 ±6%（脚步 ±10%）；同一声音设有最短间隔，避免连成一片。
- 浏览器要求用户先有一次点击或触摸才能出声：手机在点击"进入游戏"时解锁，大屏在第一次点击按钮时解锁。
- 调试和测试：每次播放会把声音 ID 记入 `window.__jjAudio`，背景音乐的播放状态记在 `window.__jjMusicPlaying`。
- 待替换：主题音效（纸张、沙土、灯笼等）和分时代背景音乐计划用 AI 生成（ElevenLabs、Suno），替换 `sounds.json` 中对应的文件后重新生成即可，代码不用改。
