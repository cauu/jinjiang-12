# 白模流程蓝图

> 2026-10-27 · 用 Three.js 白模把整局流程、每屏 UI、每关场景、背景天空和三段影片的位置与尺寸先画出来，开工前三人对齐。

## 打开

双击 `index.html` 即可（需要联网，Three.js r180 从 jsdelivr 加载）。也可以 `npx serve docs/blueprint` 后在浏览器打开。

- 顶部流程条：扫码入场 → 大厅 → 片头（可选）→ 六关（中间夹切关/风起/再生）→ 结局，点任一节点跳转。
- 设备：手机 844×390 / 大屏 1920×1080 / 并排。镜头：游戏镜头 / 全景俯视 / 自由旋转。
- 显示：3D 标注、尺寸、UI 框、责任色（按 U/A/B 上色）、只看 P0。
- 时间轴：每关是史实卡 6s → 倒数 3s → 游玩 → 结算 5s（另有淘汰观战）；影片按镜头表分段。▶ 播放会按真实时长走完整局，空格暂停，←/→ 切屏。
- 点击 3D 物体、标注或 UI 框，右栏会显示命名、包围盒、位置、负责人和任务号。

## 这一版的简化（蛋仔派对式）

概念图只用来定配色、纸感和地标造型，元素密度不按概念图来：

1. 20×20 玩法台浮在云海或水面上，外围不铺整条街；四周 2m 只放围栏。
2. 镜头正前方（北侧）一块地标台：每关 1 个地标加 1–2 个套件。
3. 每关新做的模型不超过 2 个，摊位、彩旗、灯笼、纸树、围栏都用通用套件换色或换招牌。
4. 不做 3D 群众，热闹感由 B 出的剪影立牌和远景卷轴承担。
5. 角色只有一个圆胖纸人，每关换一顶帽子，不做朝代服装体系。
6. 背景和天空分五层，全部由 B 出图：天空球、远景卷轴环、中景纸片、漂浮纸云、云海/水面。
7. 片头、风起、再生、结局都是全屏 CG，手机和大屏同步播放：大屏 1080p 带声音，手机 720p 静音铺满屏幕（`*_phone.mp4`）。手机会裁掉源片上下各约 96px，所以字幕和关键画面要放在中间 1920×888 的范围内。手机端在上一关游玩时预加载，加载失败就显示同时长文字卡，到点照常进下一关。
