## 叙事与场景

兴（锦市生产交易）→盛（灯市观灯）→极盛（七宝市商贸）→落（同地风起散市）→再生（酒市重建）→归（桂市登高团圆）。

市散取「人群正在收摊离场」的时刻，外围仍有大量带货人流，同时通过熄灯、关铺和纸街折落保留低谷；不是空无一人的废墟。第三、四关以大慈寺门、交子铺、铁钱与珠饰建立同地对照。

六张均为历史背景下的游戏演绎。月份市名来自宋代记载，跨时代章节不等于认定各朝代已有相同市场制度，也不证明图中每处服饰、建筑布局和市场位置。各关说明区分依据与演绎边界。

## 已完成的修改

- 锦市：从少量人物的作坊展示，改为展锦、议价、挑选和货运并存的街市；补上纸台边界、纸材质与可辨主角。
- 灯市：收敛偏晚的建筑轮廓，增加花形灯、灯树、明显选择区与塌落边缘。
- 市散：补上与七宝市相同的大慈寺门、交子铺、铁钱车与收拾中的珠饰摊。
- 酒市、桂市：更换原先重复的宋式帽/交领袍，加入清式衣帽、辫发与盘扣短装，桂市增加民初短发形象。
