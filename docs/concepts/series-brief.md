# 六关折纸市集概念设计与验收简报

日期：2026-10-27。用户要求：所有关卡契合对应朝代与市场背景；场景能还原「十二月市」热闹、熙熙攘攘的感觉；每张最终概念稿须由 Claude Opus 实际看图、明确验收通过。当前阶段仅评视觉设计与玩法表达，不扩展到网络、碰撞、性能和程序细节。

## 设计背景与已确定的方向

- 游戏《锦江十二月市 · 千年赶集》，手机派对淘汰赛，6 关跨时代展开：锦市（汉）→灯市（唐）→七宝市（北宋）→市散（宋元之际）→酒市（清初）→桂市（清末民初）。
- 折纸、纸雕、立体书结合的简化 3D 风格，颜色清楚，结构可辨，薄纸边与折面可见。纸是美术媒介，不暗示历史上的物品由纸制成。
- 总体主题「市会散，人会回来」，原有情绪曲线为兴、盛、极盛、落、再生、归。
- 宋代十二月市的记载是叙事来源。把汉代织锦、唐代观灯等放到各章，是跨时代的游戏演绎，不声称宋代月份制度已原样存在于汉唐。
- 原首关概念图 `01-jinshi-paper-concept-v1.png` 仅为旧稿。它的不足是作坊展示多、真实交易少、人流与成都背景弱。本批次要重做，旧稿不算最终通过图。

## 本批次交付

六张16:9概念设计板。主画面至少占约80%，用斜俯视或决赛斜向登高视角表达实际玩法空间；小型下栏标识时代线索、市场活动与玩法意图。场景必须有连续街巷与周边人群，不能是只有四个主角、两座摊位、四周留白的玩具展台。

每张图附完整生成提示词、历史背景说明、物件和市场活动说明、独立 Opus 审核报告。主图内用少量中文标识主题，详细史实与演绎边界放伴随文档，不靠大段图中文字证明视觉达标。

## 核心构图思路

中央玩法清楚，外围集市拥挤；近处的商贩与顾客、中层连续摊位、远处街巷和人流共同建立繁华。人群应有挑选、议价、搬货、排队、制作或节庆观赏等不同动作。主角以色彩、尺度、位置区别于外围纸人。拥挤不能遮住玩法。

## 通用硬性通过条件

1. **市场人气**：锦、灯、七宝、酒、桂五关主画面需明显熙熙攘攘，至少三处可辨的交易或节庆活动群，前中后景均有人流/市场连续性；不能用文字、灯笼数量或空建筑代替热闹。可见人数以约30–60位外围纸人为设计目标，不机械数人。酒市表现忙碌复苏，密度允许低于极盛七宝市，但不能空。
2. **时代背景**：每关至少三类互相支持的可见时代线索，来自建筑、服饰头饰、器物、交易方式、纹样等。无主导性错代物件。概念级简化允许，不要求考古复原精度；不能声称画出的精确布局或服饰已被史料证明。
3. **成都与市场特异性**：清楚表现本关卖什么、做什么，以及至少一个有依据的成都历史文化联系；不能仅换牌匾和屋顶颜色就成为另一座古城。
4. **折纸风统一**：建筑、人物、商品、地面与远景共同体现纸边、折面、叠层和低对比纤维。不可主体变为木雕、陶土或写实古建；纸纹不遮盖玩法色块。
5. **玩法可读**：锦市四色走格成锦；灯市三片清楚答案区；七宝市落地交子与拾取；市散缺失地面与继续移动；酒市携粮与四处交付点；桂市从低到高的台阶、缺口、桂枝终点。不因热闹擅自改变现有核心玩法。
6. **整体质量**：构图完整、人物无显著异常、主要文字无严重错误；时代与主题、市场气氛在主画面成立，不能由说明下栏补救。

## 市散的特殊处理

用户最新的“全部热闹”与原设计唯一低谷有张力，已向用户异步询问。未获回答前，先推进其他五关。若采用原低谷，市散设计板应有明确的同地繁华→散市对照：主图表现风起、行人收摊离开与逐渐空下来的街巷，保留失落；辅助小图表现同地先前繁盛，不把废墟画成喜庆夜市。若用户要求六关都热闹，则以大量赶集人群正在散市的时刻作为主画面，保留风、撤摊、落砖。此选择在最终文档写明，不暗中豁免用户验收。

## Opus 审核输出要求

必须使用图像读取能力实际查看待审 PNG，不能仅阅读提示词。逐图独立判定 PASS / REVISE；每项0–5分，市场气氛、时代背景、成都/市场特异性、折纸统一、玩法表达均至少4分，且无上述硬性失败项，才可 PASS。评分是辅助，严重错代或空场直接 REVISE。描述图上可见证据与具体修改位置，区分阻断项和非阻断建议。

审核报告须写明实际查看的图片绝对路径、文件 SHA256、模型身份/有效模型（运行记录可核验）、结论和剩余限制。未实际看图或模型并非 Opus，必须报告无法验收，不能签署通过。不要为赶进度放宽标准，也不要新增技术实现验收项。

## 预审后的视觉裁决（协调方负责，2026-10-27）

- B1：玩法面采用抬高的纸台，外围低处是连续市场街面；掉落关露出台边与下方空隙。热闹的围观/交易人群留在玩法面外。锦市与酒市有矮栏；三选一区、四角交付、上升台阶是核心布局，精确米数、格数及出生点属于后续布局稿，不用概念板承担工程尺寸验收。
- B2：截至推进此关时未收到额外答复，采用用户最新“所有关卡有市集人气”的要求：主图取风起、赶集人群正收摊离场的瞬间，外围仍有大量带货/包裹的人流，中央纸街缺失、灯熄与货架渐空体现失落；下栏增加同地先前繁华的小图作对照。这是协调方的明确设计选择，不声称用户另行批准过低谷例外。避免空无一人的废墟，也避免喜庆围观。
- B3：以新锦市通过稿作为后续纸材质、人物比例与设计板参考；已生成的灯市也必须接受同样审核，不能自动算通过。标题左上，主场景约80%，下栏三项小图；六关保持一致，允许桂市为登高镜头。
- B4：本批最新视觉简报优先于旧关卡文档的概念图段落；核心玩法不改。灯市不以空中孔明灯为主景；酒市蒸汽从灶/甑出，交付用粮纹亮起而非冷坛冒烟；桂枝是木犀桂花枝，不使用西式月桂冠。锦市用可辨的朱红、靛蓝、黄与深绿队色，黄色服务于玩法识别，不被解释为帝王身份。
- B5：外围群众与商品降低饱和度，主角通过衣色、尺度和场内位置突出；锦市商品可保留必要彩色纹样，否则无法说明锦匹贸易。缩到约480像素宽时，须仍能找到玩法主角和场地边界。
- 整体质量至少3分且无明显人物异常；最后再单独检验六图是否像同一套，包括纸质、角色、版式及情绪曲线。历史审核按已列来源和可见图像判断，不能将未核实的审核者直觉当成确凿年代结论。
- 主角换装裁决：保留同一纸人比例与描边，不把同一套汉宋交领袍复制到清代章节。酒市主角改为清式圆帽、圆领短褂长裤；桂市改为相同清式短装，少量短发形象配合民初背景。群众同步换成该时代的日常衣冠，妇女不剃发。这里只定义视觉造型，未增加玩法系统。
