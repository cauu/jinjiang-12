## 3. 阻断项与修改位置

1. **外围男子换成清式服饰**（阻断）。至少覆盖画面里最显眼的三组人：左侧试饮队伍、黑衣舀酒掌柜、右下挑夫和推车人。
   - 衣：改成圆领、右侧大襟的长衫，领口和襟边不要白色交领边；干活的挑夫、蒸粮工改成及膝或更短的短褂加长裤、绑腿；掌柜可以加一件深色对襟短褂（马褂），胸前有一排扣子。
   - 帽：一部分人改成六瓣拼合、顶上有小结的瓜皮帽，干活的人可以光头或包头巾，不要再用 03 那款有棱角的软巾。
   - 辫：部分男子脑后一条明显的长辫，从后脑正中垂下，要和巾子的垂带区分开（辫子是一条有编纹的圆股，不是从帽檐下伸出的扁带）。
   - 女子：保持不剃发，可以改成立领或圆领的袄裙，避免和 03 宋女同款交领。
   这些都是简报已经写明的要求，不是新增审核项。

## 4. 非阻断建议

1. 【审核判断】**主角服饰**：5 个主角仍穿交领短袍、戴软巾，和 03 主角一模一样。如果主角是贯穿六关的固定形象，这可以保留；如果每关要换装，建议酒市主角至少换成短褂或加瓜皮帽，免得主画面中央最显眼的人物继续指向宋代。这个需要协调方定。
2. **纸感**：木甑和桶改成卡纸圈加纸条箍；摊晾的粮改成碎纸粒或印刷纸面；屋架方条加折线和纸舌。
3. **文字**：副标题统一成一个颜色；修正蓝幌上写坏的“酒”字。
4. 主角配色：两名深绿主角深浅相同，缩小后难区分。
