## 4. 非阻断建议（不影响本次通过）

1. **文字**：左下横牌改成清楚的“桂花糕”。
2. **民初线索**：把一两个短发短装人物放到前景或中景较大的位置（比如左下桂花摊顾客），不用放大也能看到。

4. **台阶缺口**：缺口边缘的台阶可以微微向下翻折，和 04 的“纸格折落”呼应。
