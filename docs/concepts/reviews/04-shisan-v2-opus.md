## 4. 非阻断建议（不影响本次通过）

1. 左上亮灯铺面：炉火减弱或熄掉，柜前交易的人改成收拾或转身离开；左下珠饰托盘拿走一部分。能让“货架渐空”（B2）在左右两边一致。
2. 风：再加几张从纸格上被吹起的纸片、几面斜飘的幡，把“风起”和“纸格折落”连起来。
3. 纸格表面去掉石板式灰斑，改成低对比纸纤维；缺口下的灰方块改成翻倒的纸台。
4. 两名深绿主角深浅一样，缩小后不好分；和系列队色一起定（见 `07-series-final-opus.md`）。
