## 3. 非阻断建议（不影响本次 PASS）

1. **纸感**：摊架、矮栏立柱加折线或浅色纸芯边；铁钱捆改成黑色卡纸圆片串在纸绳上，去掉金属高光；玉璧改成哑光的厚纸圆环。和锦市 v3 第 4 节第 1 条一起处理。
2. **飘落和落地的区分**：落地纸票可以稍大、平贴台面，或加一点浅色投影；飘在空中的保持倾斜和更淡的颜色。
3. 【审核判断】**加一两位直脚幞头的商人或吏员**，例如放在交子铺柜台后，让宋代服饰不只靠一款高方巾。这只是美术判断。
4. **主角配色**：两名红衣主角换成差别更大的颜色，或和其他关保持统一的分队配色。
5. **版式统一**：本图保留了副标题、演绎说明和下栏小标签，和灯市 v2 一致、和锦市 v3 不一致，等六图统一检验时一起定。
