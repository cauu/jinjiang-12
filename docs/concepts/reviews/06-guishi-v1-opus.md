## 3. 阻断项与修改位置

1. **外围人物换成清末民初的混合服饰**（阻断）。至少覆盖左侧两个桂花摊、“桂花茶”摊前的队伍、右侧码头挑夫这几组最显眼的人：
   - 多数男子：圆领右侧大襟长衫，不要白色交领边；一部分加深色对襟马褂；头戴六瓣拼合、顶上有小结的瓜皮帽；一部分人脑后有长辫。
   - 少量人（简报写的是“少量”）：剪短发、不戴帽，或穿立领短装，用来表示民初。
   - 码头挑夫、船工：短褂、长裤、绑腿或草鞋，可以保留斗笠。
   - 女子：立领或圆领大襟袄配长裙或长裤，发髻或长辫都可以；不要再用 03 的交领上衣。
   - 去掉 03 那款黑色高方巾。
   这些都是简报已经写明的要求，不是新增审核项。

## 4. 非阻断建议

1. 【审核判断】**主角服饰**：4 个主角仍穿交领短袍、戴软巾，和 03、05 主角相同。是否按关换装，和 05 一起由协调方定。
2. **成都辨识度**：把石栏桥换成木梁桥或渡口跳板，河岸改成土石混合的码头斜坡，船换成川江常见的木船样式，减少江南水乡感。
3. **纸感**：台阶侧面加纸板层线和折边，让它读成卡纸台阶；水面倒影改成几条剪纸波纹加少量光点；减弱后景虚化。
4. **台阶缺口**：缺口目前都是规整的深蓝方块，可以让缺口边缘的台阶微微向下翻折，和 04 的“纸格折落”呼应，同时更像会掉下去的地方。
