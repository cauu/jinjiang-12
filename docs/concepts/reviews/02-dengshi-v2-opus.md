## 4. 非阻断建议（不影响本次 PASS）

1. 【审核判断】**远景的深色多层方楼**：右上角和中上方屋顶后面，有几栋平顶、开着方窗的深色多层建筑。现在又小又暗，不显眼，但放大后有点像现代楼房的剪影。建议换成低矮的屋脊线，或者一座唐式的塔或楼阁。
2. **侧面空隙**：在纸台左右两侧也露出一条窄的深色缝，让“四边都会掉下去”更明确；甲区前沿的下折片画成有折痕的硬卡纸边板，不要像一块毛边布。
3. 【审核判断】**红流苏**：几乎每盏灯下面都挂着红色长流苏，这是后世灯彩常见的样子。可以减掉一部分，或者换成短穗、彩带。这只是美术判断，不是确定的年代结论。
4. **成都的联系**：如果想让画面本身更有成都的区分度，可以在远景放一段江岸和临江店铺，或者在灯摊边挂几匹锦缎呼应锦市，但不能变成锦市的复制品。
5. **主角配色**：左边（甲区）和右边（丙区）两个主角都是红色系，只是深浅不同，缩小后容易看成同一个颜色。如果本关用颜色区分玩家，建议换成两种差别更大的颜色。
6. **版式统一**：本图保留了副标题、演绎说明和下栏小标签，锦市 v3 去掉了，两张现在不一致，等六图统一检验时一起定。
