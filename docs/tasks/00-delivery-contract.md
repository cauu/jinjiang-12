# 共同交付约定

> 开工默认约定，U01由开发者在首轮样板接入前补齐尺寸/锚点。目录是计划交付位置，不表示资源已存在。
> 依据：[六关定稿](../concepts/README.md)、[视觉验收标准](../concepts/series-brief.md)。

## 1. 文件归属

```text
assets/art/shared/                  A：纸纹、角色、模块、交互道具
assets/art/levels/<level-id>/       A：六关静态场景与摆放说明
assets/backgrounds/<level-id>/      B：远景与远处群众层
assets/ui/                         B：按钮、边框、图标、界面样板
assets/content/                    B：题库、历史/演绎卡、界面文字
assets/audio/                      B：配乐、环境与单次音效
assets/video/                      B：风起、再生、结局及占位文件
production/art/                    A：源文件、生成脚本/提示词
production/media/                  B：分镜、关键帧、工程与源音轨
production/delivery/               各批清单、预览、来源记录
```

关卡ID固定为 `01-jinshi`、`02-dengshi`、`03-qibaoshi`、`04-shisan`、`05-jiushi`、`06-guishi`。不使用“最终最终版”文件名；修改包写清变更，历史源稿留在production。

## 2. 最低交付格式

| 类型 | 交付 | 默认约定/完成条件 |
|---|---|---|
| 单体/场景 | GLB＋贴图＋预览＋源文件或脚本 | 米为单位、Y向上；原点/落地点明确；可独立打开，不丢贴图 |
| 角色 | 分件GLB＋染色/挂点说明 | 默认root/head/body/arm_l/arm_r/leg_l/leg_r；身高朝向由U01冻结；若另约骨骼，需动作名称表 |
| 场景包 | scene.glb＋handover.md＋节点/摆放清单 | 不焊死动态地格、交子、粮袋、选择字或触发物；按你提供的白模基准装配 |
| 远景 | JPG/WebP底层；需要时透明PNG/WebP前层 | 默认2048×1024，前层不能遮玩法；不把玩法人物和地面画进背景 |
| 纸纹/图标 | 可平铺PNG/WebP；透明PNG/SVG | 纸纹先512，共用灰/米白底后染色；不烘焙动态题目 |
| UI | 样板图＋拆分图形＋字号/色板/字体名 | 横屏844×390参考，左右各44px安全区；按钮、背景、文字分开 |
| 内容 | 可解析JSON＋来源/人读说明 | 稳定ID；字段在U01/B01对齐，不重复实现两份题库 |
| 音频 | 可播放文件＋源音轨＋循环/触发说明 | 配乐MP3/AAC；音效用浏览器实测可播格式；循环无明显断口，响度一致 |
| 视频 | 1080p H.264 MP4＋首末帧＋工程/字幕/源音轨 | 1920×1080、全套统一25或30fps、AAC音轨；时长与叠字区域见媒体任务包 |

每包附文件大小；沿用原设计单体预算，首轮实机导入后再调整。15MB游戏资源目标不含视频，A/B提交大小清单，你汇总首包。

## 3. 接口边界

- 你用几何体、占位题和占位媒体持续研发，不依赖正式美术。
- 你尽早给A镜头截图、玩法面范围、禁放区、物件锚点及桂市路线。A先做模块，不必等齐所有截图。
- A不修改地格编号、玩法尺寸、答案区、交付点和决赛路线；需要调整回到你维护的白模布局。交互物件有稳定名字，你绑定玩法对象。
- B远景负责街巷/远处人流，A近景负责可辨活动小组；共享衣冠和色板。外围群众不新增碰撞或AI玩法。
- B影片可烧录固定字幕；姓名、冠军、实时名单、合影由网页叠加。手机关间卡和大屏视频统一时间，避免重复大段字幕。
- 默认分件纸人＋程序动作，A交节点，U02驱动动作；如改为骨骼动画须在U01明确，避免动作无人负责或重复制作。

## 4. 每次交付必须带上

handover.md写任务ID、文件列表/大小、版本、预览、使用/摆放方式、来源/生成记录、已知缺项、需要程序触发的内容。缺文件或未看过效果时标待验，不标完成。

第一轮就拿一套角色、一关场景、一段占位/短片实际接入；之后小批交付，不等全套完美。

## 5. 视觉与内容验收

每关能看到交易、制作、搬运或节庆活动，前中后景有人气；市散是收摊离场。商品/衣冠/建筑契合该时代，清代不能继续复用宋帽。玩家与群众分开，纸风统一，玩法字/地面/道具清楚。

概念图小字不直接作为贴图；史实、年代、地点按伴随说明再次核对，标明游戏演绎，AI图不是史料。资源验收在实际游戏镜头里进行。
