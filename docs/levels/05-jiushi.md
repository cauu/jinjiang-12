## 1. 概述

| 项 | 内容 |
|---|---|
| 月市 / 时代 | 十月酒市 · 清初 |
| 情绪 | 回升（3/5）：重建、齐心 |
| 原型 | 运送道具类收集赛 |
| 使用的引擎 | 拾取引擎（含交付） |
| 时长 | 最长 60 秒 |

**史实卡**（6 秒）：
> 【史实】清初“湖广填四川”，各地移民入川重建家园；水井坊遗址留下了明清酿酒的完整流程。
> 规则：把粮袋运进酒坛，最先运满 3 袋的人晋级。

## 2. 规则

- 平台上散落着粮袋。走到粮袋旁自动扛起，**一次只能扛一袋**。
- 扛着粮袋走进任意一个酒坛的交付区（半径 1.5 米），自动交付并计 1 袋。
- 交付满 3 袋就**立即晋级**，角色欢呼后退到场边观战。
- 结束条件（满足任一）：
  - 晋级人数达到名额（比例 0.6），立即结束，其余人淘汰。
  - 60 秒到时，按交付袋数排名补足名额；袋数相同时，先达到这个数量的人优先。
- 扛着粮袋的人掉出平台（本关平台四周有矮墙，正常不会掉）时，粮袋回到原位。

## 3. 布局

```
 北
 ┌────────────────────────────────────┐
 │ [酒坛]                        [酒坛] │
 │                                      │
 │         粮袋随机散落在中间区域          │
 │                                      │
 │ [酒坛]                        [酒坛] │
 └────────────────────────────────────┘
 南      出生区：南侧中央 8 × 3
 （周边道具：重建中的酒坊、木料堆、粮仓）
```

- 四个酒坛放在四个角落，每个交付区半径 1.5 米。
- 粮袋只出现在中间 14 × 14 的区域。
- 平台四周有 0.6 米高的矮墙。

## 4. 参数（可调）

| 参数 | 值 |
|---|---|
| 场上粮袋数 | 在场人数 × 2，最少 6 个 |
| 补充 | 被拾起后 1 秒，在随机位置补一个新的 |
| 拾取半径 | 0.8 米 |
| 扛粮时的移速 | 不变（不做减速） |

## 5. 同步

- 粮袋的生成位置由随机种子推算；被拾起后的补充位置同样由种子决定。
- 拾取和交付：手机上报 `pickup` / `deliver`，服务器裁决后广播 `item`。

## 6. 界面

- 右上：“已运 n / 3 袋”，以及“已晋级 x / y 人”。
- 扛着粮袋时，角色头顶显示粮袋。

## 7. 镜头

使用通用镜头。

## 8. 表现

- 每交付一袋，对应酒坛上方冒出一缕炊烟。
- 全场累计交付数分 3 档，周边的酒坊由“木架子”逐步变成“完整的酒坊”（准备 3 个阶段的模型直接替换，不做生长动画）。

## 11. 音频

- 配乐：川调，唢呐或竹笛，节奏逐渐变得明快。
- 音效：扛起粮袋、倒入酒坛的“哗”声、晋级欢呼。

## 12. 验收

- 粮袋生成和补充位置在所有手机上一致。
- 两人同时拾取同一袋时只有一人得到。
- 提前达标和到时补足两种结束方式都正确。
