## 1. 概述

| 项 | 内容 |
|---|---|
| 月市 / 时代 | 正月灯市 · 盛唐上元 |
| 情绪 | 盛（5/5）：最华丽的一关 |
| 原型 | 自创：答题站位（只用网格和区域判定） |
| 使用的引擎 | 网格引擎（塌陷） |
| 时长 | 最长 70 秒（每题约 14 秒，最多 5 题） |
| 奇观 | 千灯齐亮（本关结束时） |

**史实卡**（6 秒）：
> 【演绎】唐代上元节，满城观灯、猜灯谜。
> 规则：跑到你认为正确的答案区，答错的地面会塌陷。

## 2. 规则

- 平台从西到东分成三片答案区（A、B、C），每片地面印着一个答案的大字，上方挂着答案灯笼。
- 每一题的流程：

| 阶段 | 时长 | 内容 |
|---|---|---|
| 出题 | 10 秒 | 题目显示在顶部和大屏上，最后 3 秒大字倒数 |
| 锁定 | 瞬间 | 以这一刻每个人**角色中心所在的区域**为准判定，跳在空中也一样；落在两区之间的缝上，按离哪片中心更近算 |
| 塌陷 | 2 秒 | 答错的两片塌陷，站在上面的人掉落淘汰；答对那片的灯笼亮起 |
| 复原 | 2 秒 | 塌陷的地面升回原位，所有人回到可走动状态 |

- 结束条件（满足任一）：
  - 剩余人数 ≤ 本关晋级人数，**立即结束**。
  - 5 题出完，剩下的人全部晋级。
- **如果一题所有人都答错**，这题作废，不淘汰任何人。
- 如果一题之后剩余人数会低于晋级人数，答错的人按“离正确区域的距离”从近到远补足晋级名额，其余淘汰。
- 题目从题库里按随机种子不重复抽取。

## 3. 布局

```
 北     [题目灯笼（大）悬在平台中央上方]
 ┌──────────┬──────────┬──────────┐
 │    A     │    B     │    C     │
 │  答案灯笼  │  答案灯笼  │  答案灯笼  │
 │  地面大字  │  地面大字  │  地面大字  │
 │  6 × 20  │  8 × 20  │  6 × 20  │
 └──────────┴──────────┴──────────┘
 南        （出生区：南侧中央 6 × 3）
```

- A、C 宽 6 格，B 宽 8 格。中间区稍宽，因为出生在南侧中央，往两侧跑的距离要相近。
- 三片之间有一条醒目的分隔线（地砖描边）。

## 4. 参数（可调）

| 参数 | 值 |
|---|---|
| 每题作答时间 | 10 秒 |
| 塌陷 / 复原 | 2 秒 / 2 秒 |
| 最多题数 | 5 |
| 题干 | 不超过 15 字 |
| 答案 | 每个不超过 4 字 |

## 5. 同步

- 题目顺序、每题开始和锁定的时刻，全部由“随机种子 + 开始时间”推算，各端一致。
- 锁定时每台手机上报自己所在的区域，服务器判定后广播淘汰名单（以服务器为准）。

## 6. 界面

- 顶部：题目大字（替代平常的关卡名）。
- 地面：答案大字由程序生成文字贴图。
- 右上：“第 n / 5 题”。

## 7. 镜头

俯角稍高（55°），三片区域都在画面里。

## 8. 奇观：千灯齐亮

本关结束时（结算的 5 秒内），平台四周和远景的所有灯笼依次点亮，孔明灯从远景升起。做法是把灯笼的自发光调亮，再加实例化的发光片，成本很低。

## 9. 概念图要求

- **画面**：盛唐成都上元夜的灯市广场。平台四周是层层叠叠的花灯和高大的灯树，三片答案区各自悬着一盏大灯笼，正中上空悬着一盏最大的题目灯笼；远景是城楼、坊墙和夜空中的孔明灯。
- **光照与配色**：夜晚，灯光为主光源；主色金、朱，夜空为深蓝紫。
- **氛围**：盛大、温暖、华丽。
- **提示词草稿**：
  > 盛唐成都上元节夜晚，灯市广场，四周层层花灯和高大灯树，广场上方悬挂三盏大灯笼和正中一盏最大的谜题灯笼，远处城楼坊墙，夜空孔明灯，金色与朱红，温暖灯光，45 度俯视，[通用风格关键词]

## 11. 题库

由文案任务 36 交付 `quiz.json`，约 15 题。每题包含：题干、3 个选项、正确答案、出处。题目和成都、唐代、十二月市相关，一眼能看懂。

## 12. 音频

- 配乐：唐风，琵琶加鼓，喜庆。
- 音效：出题提示音、最后 3 秒滴答、塌陷时的木板断裂声、答对时灯笼亮起的“叮”。

## 13. 验收

- 题目顺序和锁定时刻在所有手机上一致。
- 所有人答错时作废；人数不足时按距离补足名额。
- 跳在空中被锁定时，判定正确。
