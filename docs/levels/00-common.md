# 关卡通用规范

> 2026-10-27：六关视觉方向统一为折纸、纸雕、立体书式热闹市集。[最终概念稿入口](../concepts/README.md)及[已提供给 Claude Opus 的验收简报](../concepts/series-brief.md)为当前视觉参考；本页下方早期“Q版低模平涂”提示词待具体资产制作时替换。

> 所有关卡共同遵守的规则与数值。各关文档只写和这里不同的部分。数值都是初始值，标“可调”的需要在真机上修正。
> 上级文档：[game-design.md](../game-design.md)

## 1. 坐标与场地

- 单位为米，Y 轴向上。平台中心为原点，平台顶面高度 y = 0。
- **标准平台**：20 × 20 米，由 20 × 20 块 **1 米见方的地砖**组成，地砖编号 `(col, row)`，col 从西到东 0–19，row 从北到南 0–19。
- 玩家掉到 y < −5 米即判定掉落。
- **镜头朝北**：手机画面上方是北，下方是南。玩家出生在南侧。
- 平台四周 2 米宽的一圈留给“周边道具”，玩家进不去；再往外是远景绘景。

## 2. 角色（可调）

| 项 | 值 |
|---|---|
| 碰撞体 | 胶囊，半径 0.4 米、高 1.0 米 |
| 移动速度 | 5 米/秒，起步 0.1 秒加速到满速 |
| 跳跃 | 短按跳高 0.7 米，长按（超过 0.15 秒）跳高 1.2 米 |
| 重力 | 25 米/秒² |
| 空中控制 | 可以转向，速度不超过地面速度的 80% |
| 玩家之间 | 不碰撞，可以互相穿过 |
| 动作 | 待机、跑、跳、掉落、欢呼（晋级时播放） |

## 3. 镜头（可调）

- **手机**：俯角 45°，距离角色 12 米，视场角 50°，跟随时平滑处理（约 0.15 秒延迟）。
- **大屏 / 观战**：俯角 55°，固定看全平台。
- 各关可以单独调整，例如桂市改为从坡下仰视。

## 4. 每关时间线

| 段 | 时长 | 手机 | 大屏 |
|---|---|---|---|
| 史实卡 | 6 秒 | 全屏卡片：关卡名、史实卡、一句规则 | 同步 |
| 倒数 | 3 秒 | 3、2、1；此时可以移动但不计入玩法 | 同步 |
| 游玩 | 最长 60 秒（灯市 70 秒） | 游玩 | 全场俯视 + 晋级人数 |
| 结算 | 5 秒 | “晋级”或“淘汰”全屏大字 + 欢呼/掉落动作 | 晋级名单 |
| 关间 | 2 秒 | 淡入淡出，换平台皮肤 | 同步 |

**状态归属**：关卡状态和计时由**服务器**负责；手机只负责自己的位置和上报事件。

## 5. 晋级人数（通用公式）

- 晋级人数 = `clamp(四舍五入(在场人数 × 晋级比例), 2, 在场人数 − 1)`。也就是说，决赛之前每关至少淘汰 1 人、至少留下 2 人。
- 决赛（桂市）只决出 1 人。
- 某一关开始前只剩 1 人时，直接进入结局。
- **并列**：先达到这个成绩的人优先（以服务器收到上报的时间为准）。
- **所有人同时掉落**：最后掉落的那一批人晋级（以服务器收到时间为准，相差 0.2 秒以内算同一批）。
- 被淘汰的人留在房间里观战，直到结局。

| 关 | 晋级比例 | 32 人开局示例 |
|---|---|---|
| 1 锦市 | 面积最小的一队淘汰（约 75%） | 32 → 24 |
| 2 灯市 | 0.7 | 24 → 17 |
| 3 七宝市 | 0.65 | 17 → 11 |
| 4 市散 | 0.6 | 11 → 7 |
| 5 酒市 | 0.6 | 7 → 4 |
| 6 桂市 | 决出 1 人 | 4 → 1 |

## 6. 同步事件

| 方向 | 消息 | 说明 |
|---|---|---|
| 服务器 → 全体 | `level_start` | 关卡号、随机种子、开始时间（服务器时钟）、本关参与者 |
| 手机 → 服务器 | `pos` | 自己的位置和朝向，每秒 10–15 次 |
| 服务器 → 全体 | `pos_batch` | 所有人的位置 |
| 手机 → 服务器 | `step` | 进入了一块新地砖 `(col, row)`（锦市、市散、桂市使用） |
| 服务器 → 全体 | `tile` | 地砖状态变化：染色 / 消失时刻 |
| 手机 → 服务器 | `pickup` / `deliver` | 尝试拾取某件物品 / 在交付区交付（七宝市、酒市使用） |
| 服务器 → 全体 | `item` | 物品被谁拾取、新物品生成 |
| 手机 → 服务器 | `fell` / `goal` | 掉落 / 到达终点 |
| 服务器 → 全体 | `level_end` | 晋级与淘汰名单 |

**两类事件**：
- **可以事先推算的**：用“随机种子 + 开始时间”在每台手机上算出相同结果，不需要逐个同步。例如灯市的塌陷时刻、桂市台阶的塌落时刻、交子落点。
- **和玩家行为有关的**：上报后由服务器统一裁决再广播。例如涂色、市散的踩砖、拾取、交付。

## 7. 通用界面

- 顶部：关卡名、倒计时、“晋级 x/y”。
- 左下：浮动摇杆。右下：跳跃键。
- 本关特有的信息（涂色占比、交子数量、送粮进度）放在右上，一行以内。
- 文字不小于 16px；题目等关键信息同时显示在大屏上。

## 8. 概念图规范（各关的概念图都按这个出）

**每关交付**：
1. **主概念图 1 张**（16:9）：用和游戏镜头一致的 45° 俯视角度；平台在画面中央，周边道具环绕，远景层次和光照、氛围都画出来。
2. **标注版 1 张**：在主概念图上标出每件要建模的资产名称，并和本关的资产清单一一对应。
3. 以本关的**布局图**为准：玩法区域的位置和大小不能为了好看而改。

**通用风格关键词**（来自风格圣经，定稿后替换）：
> Q 版卡通，低多边形，平涂着色，轮廓清晰，色块大而简洁，中国古风，派对游戏，柔和的全局光，无写实贴图
> chibi cartoon, low poly, flat shading, clean silhouettes, simple large color blocks, ancient Chinese style, party game, soft global illumination, no realistic textures

**单件设定图**：单体、正面或三视图、纯色背景、平光无投影，提示词带上通用风格关键词。
