# 关 1 · 锦市 · 汉 · 锦官城

## 1. 概述

| 项 | 内容 |
|---|---|
| 月市 / 时代 | 四月锦市 · 汉代 |
| 情绪 | 兴（3/5）：开局热身，轻松、热闹 |
| 原型 | 涂色（蛋仔积分赛同类玩法） |
| 使用的引擎 | 网格引擎（染色） |
| 时长 | 60 秒 |

**史实卡**（6 秒）：
> 【史实】汉代设锦官专管蜀锦，成都因此被称为“锦官城”。
> 规则：走过的格子会染上本队颜色，60 秒后面积最小的一队淘汰。

内部出处：汉设锦官；老官山汉墓出土西汉提花织机模型（见设计文档参考资料）。

## 2. 规则

- 开局按在场人数随机均衡分队：8 人及以上分 4 队；4–7 人分 2 队；少于 4 人不分队，每人一种颜色。
- 角色进入一块地砖时，这块地砖染成本队颜色，可以覆盖别队已染的格子。
- 60 秒结束时统计各队格子数：
  - 分队时，**格子最少的一队整队淘汰**。
  - 不分队时，格子最少的 1 人淘汰。
  - 格子数相同的，后达到这个数量的一方淘汰。
- 平台四周有围栏，这一关不会掉落。

## 3. 布局

```
 北                     （周边道具：织机、锦匹架）
 ┌────────────────────────────────────┐
 │ 围栏                                 │
 │   [队 A 出生]            [队 B 出生]  │
 │                                      │
 │              20 × 20 锦面              │
 │          （初始为未染色的素绢）        │
 │                                      │
 │   [队 C 出生]            [队 D 出生]  │
 │                                      │
 └────────────────────────────────────┘
 南                     （镜头在南侧）
```

- 四个出生区分别是四角各 3 × 3 格。
- 平台四周 0.8 米高的木围栏（结构件）。

## 4. 参数（可调）

| 参数 | 值 |
|---|---|
| 地砖 | 1 米，共 400 格 |
| 时长 | 60 秒 |
| 染色上报 | 进入新格子时上报一次，服务器每 0.2 秒广播一次变化 |

## 5. 同步

- 手机上报 `step (col, row)`；服务器按收到的先后顺序染色，再批量广播 `tile`。
- 结束时以服务器上的统计为准。

## 6. 界面

- 右上：4 队的颜色条，长度表示格子占比，本队有标记。
- 结算时大屏显示各队格子数。

## 7. 镜头

使用通用镜头。

## 8. 概念图要求

- **画面**：汉代锦官城的织锦坊外场。平台本身是一块铺开的巨大蜀锦，经纬纹理清晰，四个角落已经染上朱红、宝蓝、明黄、墨绿四色；平台四周是木制提花织机和晾晒锦匹的木架；远景是汉阙、夯土城墙和一条映着彩色的江。
- **光照与配色**：上午的暖阳；主色为赭红、玄黑，点缀蜀锦的四种队色。
- **氛围**：热闹、明快、有手工业的生气。
- **提示词草稿**：
  > 汉代成都锦官城，织锦作坊外的广场，地面是一块巨大的蜀锦，经纬纹理，四角染成朱红、宝蓝、明黄、墨绿，四周是木制提花织机和晾晒锦匹的架子，远处汉阙与城墙，江水映出彩色，上午暖阳，45 度俯视，[通用风格关键词]

## 10. 音频

- 配乐：汉风，编钟加鼓点，节奏轻快。
- 音效：染色时轻微的“沙”声（同一时间最多播放 3 个，避免嘈杂）。

## 11. 验收

- 32 个模拟客户端同场涂色，结果和服务器统计一致。
- 4 队、2 队、不分队三种情况都能正确结算。
- 真机帧率不低于 30。
