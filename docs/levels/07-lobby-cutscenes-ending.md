# 入场大厅、过场与结局

> 2026-10-27 制作入口：[内容与媒体任务包 B05–B09](../tasks/03-content-and-media.md)已将风起约8秒、再生约6秒、结局45–60秒分别拆成分镜、关键帧、成片和交付验收；其最新分镜优先于本页早期描述。风起/市散保留收摊离场的人流，再生以纸页/叠化表达跨时代，实时冠军/名单/合影由网页叠加。

> 通用规范见 [00-common.md](00-common.md)。
> **视频只在大屏播放**；手机上只显示文字卡和结局页，不播放视频。

## 1. 入场大厅

| 项 | 内容 |
|---|---|
| 场景 | 复用锦市平台（不染色），平台北侧立一块写着游戏名的标题牌 |
| 手机 | 扫码 → 输入名字 → 选身体颜色（8 种）→ 进入大厅自由跑跳 |
| 大屏 | 二维码、在场人数、平台俯视、所有人的名字 |
| 房主 | **大屏页面就是房主**，上面有“开始”“跳过本关”“直接结局”三个按钮 |
| 开局 | 房主按“开始”；建议至少 4 人再开局 |
| 资产 | 标题牌 `lobby_prop_titleboard`（不超过 2,000 面） |

## 2. 过场 · 风起（关 3 → 关 4）

| 项 | 内容 |
|---|---|
| 时长 | 约 8 秒 |
| 文字卡 | 【史实】宋元之际，战火入城。此后，十二月市渐渐衰落。 |
| 大屏 | 视频：宋代繁华的街市灯火一盏盏被风吹灭，街道在风沙中沙化消散。基于现有街市转场录屏剪辑调色，不够的镜头用 AI 视频补 |
| 手机 | 文字卡 + 平台渐暗 |
| 分寸 | 只有风、熄灯、空街，不出现兵器、伤亡和战斗 |
| 降级方案 | 来不及做视频时，大屏也只显示文字卡 |

**关键帧要求**（给视频关键帧生成用）：
1. 宋代街市灯火通明（可以直接用七宝市概念图）。
2. 一阵风沙卷过，灯一盏盏熄灭。
3. 空街在风沙中只剩轮廓，色调转为灰褐（衔接市散概念图）。

## 4. 结局 · 锦江十二月市（当代）

| 项 | 内容 |
|---|---|
| 时长 | 45–60 秒 |
| 大屏视频 | 古代街市灯火 → 时光流转 → 今天的东门码头和锦江夜景 → 当代十二月市的热闹人群与十二个月市的摊位依次亮起 → 河灯顺江漂下 → 结尾留出约 8 秒空镜 |
| 大屏叠加（网页元素） | 冠军名字与桂冠；全体玩家名单滚动；最后的空镜上显示全场“合影”（所有角色站在平台上的定格画面，由游戏实时渲染后截图） |
| 手机 | 结局页：“冠军 xxx”，以及“你走到了第 N 关” |
| 素材 | 古代部分用 AI 视频；**当代部分用有授权的素材或 AI 生成**（两天内不安排实拍） |
| 降级方案 | 名单滚动 + 合影定格，不放视频 |

**关键帧要求**：
1. 古代街市灯火（复用灯市或七宝市概念图）。
2. 时光流转的转场（同一位置，古今叠化）。
3. 当代东门码头夜景，锦江倒映灯光。
4. 十二月市的摊位依次亮灯。
5. 河灯漂满江面的空镜（留给合影叠加）。
