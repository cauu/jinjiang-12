## 1. 概述

| 项 | 内容 |
|---|---|
| 月市 / 时代 | 七月七宝市 · 北宋 |
| 情绪 | 极盛（5/5）：繁华的顶点，风起之前的最后一关 |
| 原型 | 抢金币类收集赛 |
| 使用的引擎 | 拾取引擎 |
| 时长 | 60 秒 |
| 奇观 | 交子雨（整关持续） |

**史实卡**（6 秒）：
> 【史实】北宋时，成都出现交子，被视为世界上最早的纸币之一。【演绎】本关借七宝市展现交子流通的盛景。
> 规则：捡交子，60 秒后捡得最少的人淘汰。

## 2. 规则

- 交子从空中飘落到平台上，落地后走过去即可拾取（拾取半径 0.8 米）。
- 每张交子只能被一个人拾取，先到先得（以服务器收到的先后为准）。
- 60 秒结束时按拾取数量排名，取晋级人数（比例 0.65）；数量相同时，先达到这个数量的人优先。
- 落地 8 秒后还没人捡的交子会消失。

## 3. 布局

```
 北    （周边道具：交子铺、珠宝摊、钱铺招牌）
 ┌────────────────────────────────────┐
 │                                      │
 │        交子随机落在整个平台上          │
 │                                      │
 │            20 × 20 青石板             │
 │                                      │
 │        出生区：南侧中央 8 × 3          │
 └────────────────────────────────────┘
 南
```

摊位全部放在平台外的周边一圈，平台内没有障碍物，不需要额外的碰撞检测。

## 4. 参数（可调）

| 参数 | 值 |
|---|---|
| 落下频率 | 每秒约（在场人数 × 0.5）张 |
| 落下时间 | 从 6 米高飘落，约 2 秒，带翻转；落地后才能拾取 |
| 落点 | 由随机种子决定，避开平台边缘 1 格 |
| 存在时间 | 落地后 8 秒 |

## 5. 同步

- 每张交子的出现时刻和落点由“随机种子 + 开始时间”推算，各端一致，不需要逐个同步。
- 拾取：手机上报 `pickup (交子编号)`，服务器裁决后广播 `item`，未抢到的一方画面上的交子随之消失。

## 6. 界面

- 右上：“我的交子 n · 当前第 k 名”。
- 结算时大屏显示排名前几位。

## 7. 镜头

使用通用镜头。

## 8. 奇观：交子雨

整关持续飘落的实例化纸片，带轻微翻转。结算时额外落下一阵更密的交子，持续 2 秒。

## 9. 概念图要求

- **画面**：北宋成都七宝市的白天。平台四周是交子铺、珠宝摊、钱铺，挂着招牌和幌子；空中飘着一张张交子，平台上散落着刚落下的交子；远景是宋代楼阁和繁华街市。
- **光照与配色**：晴朗的午后；主色青绿、素白，点缀金色与交子的米黄。
- **氛围**：富足、热闹、轻盈。
- **提示词草稿**：
  > 北宋成都七宝市白天，广场四周是交子铺、珠宝摊和钱铺，挂着招牌和幌子，空中飘落一张张纸币交子，地面散落交子，远处宋代楼阁和繁华街市，青绿与素白，点缀金色，晴朗午后，45 度俯视，[通用风格关键词]

## 11. 音频

- 配乐：宋风，笛子加古筝，轻快明亮。

## 12. 验收

- 交子落点和出现时刻在所有手机上一致。
- 两人同时拾取同一张时，只有一人得到，另一方画面上的交子也正确消失。
- 排名与并列规则正确。
