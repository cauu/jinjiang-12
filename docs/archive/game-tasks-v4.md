## 2. 关键路径

- **程序**：57 灰盒 + 1 联机骨架 → 3 关卡框架 → 4 网格四关 → 9 接入 → 12 调优 → 51 彩排
- **3D**：13 风格圣经 → 14 色彩脚本 → 57 灰盒 → 15 概念图 + 16 布局图 → 17 单件设定图 → 18–22 模型 → 27 验收
- **视频**：15 概念图 → 42 分镜 → 43–45 → 47 剪辑导出 → 8 播放与叠加

**关卡概念图（15）和布局图（16）是新的关键节点**：远景绘景、单件设定图、视频分镜都要等它们。第 1 天上午风格圣经一定稿就要开始出图，先出最早开发的市散、锦市两张。

## 3. AI 工具选型（开工前各选定一个主力，备一个替补）

| 环节 | 主力（示例） | 注意 |
|---|---|---|
| 风格圣经、概念图、设定图、远景、界面、贴图、视频关键帧 | Midjourney、即梦、GPT 图像、Flux 等任一 | 用同一组风格参考图和提示词 |
| 图生 3D | **Meshy**（备选 Tripo、混元 3D） | 低模模式、设定目标面数、导出 GLB；免费版有限制，公开展示用付费版 |
| 自动绑骨与动作 | Meshy 自带（备选 Tripo） | 角色用 A 字或 T 字站姿生成 |
| 视频 | 可灵、即梦、Runway 等图生视频 + 剪映剪辑 | 每段 5–10 秒，先出关键帧再生成 |
| 配乐 / 音效 | Suno（付费版）/ ElevenLabs | 免费版生成内容不能商用；以官方最新条款为准 |
| 文案初稿 | 大语言模型 | 只当初稿，必须人工核对出处 |
| 代码 | AI 编程助手 | — |

## 4. 资产规格

| 类别 | 数量 | 规格 |
|---|---|---|
| 角色 | 1 个 + 5 个动作 | 不超过 2,000 三角面；贴图 1024；身体部分用浅灰或白色，由程序染色 |
| 帽饰 | 6 个（5 顶时代帽 + 桂冠） | 每个不超过 500 面；贴图 256 |
| 平台与结构件 | 约 6 种 | 每件不超过 2,000 面 |
| 每关大件 | 6 关 × 1–2 件 | 每件不超过 5,000 面；贴图 1024 |
| 每关小道具 | 6 关 × 3–4 件 | 每件不超过 1,500 面；贴图 512 |
| 拾取物与交付点 | 4 件 | 每件不超过 800 面；贴图 256 |
| 地砖贴图 | 7 张 | 512，可四方连续 |
| 远景绘景 | 12 张 | 2048×1024，前层带透明通道 |
| 界面 | 约 15 件 | 横屏基准 844×390，左右各留 44 像素安全区 |
| 配乐 / 音效 | 6 段 + 风声 / 约 10 个 | 配乐 60–90 秒可循环，每段不超过 1MB |
| 视频 | 3 段（+ 可选片头） | 1080p MP4，只在大屏播放，不计入首包 |

**命名**：`时代_类别_名称`，例如 `tang_prop_lantern.glb`。时代代号：han / tang / song / yuan / qing / minguo / today。
**首包**：游戏资源合计不超过 15MB（不含视频）。

## 5. 3D 生成流程

1. **风格圣经**：Q 版汤圆小人 + 唐代建筑，同一画风，平涂或卡通着色，轮廓清晰。
2. **色彩脚本**：按情绪曲线给每关和每段过场定主色与光照。
3. **关卡概念图 + 布局图**：概念图负责好看，布局图负责好玩；两者对齐后，列出每关的资产清单。
4. **单件设定图**：单体、正面或三视图、干净背景、平光无投影，提示词带统一风格关键词。
5. **图生 3D**：低模模式加目标面数，每件生成 2–4 个版本，挑最好的一个；角色额外做自动绑骨和动作。
6. **清理脚本**：统一单位、原点、减面、贴图压缩、命名，并输出报告。
7. **引擎内验收**：在游戏里看比例、颜色和手机帧率。单件生成三次仍不理想，就简化造型或删掉，单件不超过 30 分钟。

## 6. 风险

| 风险 | 应对 |
|---|---|
| AI 生成的风格不统一 | 第 1 天中午前锁定风格圣经和色彩脚本；所有生成都带同一组参考图和提示词 |
| 概念图拖慢后续环节 | 先出市散、锦市两张，其余边建模边补 |
| 模型面数高、贴图多 | 低模模式 + 目标面数；清理脚本统一减面、缩贴图 |
| 自动绑骨效果不好 | 角色保留清楚的短手短脚；实在不行改用程序做缩放弹跳动作 |
| 工具排队或额度用完 | 每个环节备一个替补工具；分批并行生成 |
| 免费版不能商用或带水印 | 公开展示的资产一律用付费版生成并登记 |
| AI 文案出现史实错误 | 逐条核对出处，审阅人确认后才能上线 |
| 2 天做不完 | 按“可砍”标记依次砍：拾取两关 → 片头 → 风起/再生降为文字卡 → 结局降为名单定格；保底版本是锦市 → 市散 → 桂市 + 名单结局 |
